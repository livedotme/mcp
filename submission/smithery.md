# Smithery (smithery.ai)

1. Sign in on smithery.ai with GitHub.
2. **Publish a server → an existing remote server (URL)**: `https://livedot.me/mcp`. No configuration, no authentication.
3. Name **livedot MCP**, namespace `livedot` if offered; description, homepage and repository from [common.md](common.md); icon `logos/livedot-512.png`.
4. Smithery reads the tools from the server itself. `../smithery.yaml` records the same facts in the repo.
5. Once listed, replace the Smithery badge link in `../README.md` with the server's own page and badge (`https://smithery.ai/badge/<id>`).
