# Glama (glama.ai/mcp)

1. Make github.com/livedotme/mcp public (README, LICENSE, `glama.json`).
2. Put your GitHub username in `../glama.json` (`"maintainers": ["…"]`) and push: it lets you claim the listing.
3. On glama.ai/mcp/servers, **Add server** with the repo URL. Glama reads the README and LICENSE and checks the server.
4. It's a hosted server: add it as a remote connector too (glama.ai/mcp/connectors, **Add connector**): `https://livedot.me/mcp`, Streamable HTTP, no auth.
5. Claim it (Glama shows "Claim" once `glama.json` names you), then fill the listing from [common.md](common.md) and the logo `logos/livedot-512.png`.
6. Replace the Glama badge in `../README.md` with the listing's own (`https://glama.ai/mcp/servers/<id>/badge`).
