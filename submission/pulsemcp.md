# PulseMCP (pulsemcp.com)

PulseMCP lists servers from the official MCP Registry on its own, so publishing there first ([mcp-registry.md](mcp-registry.md)) may be enough. To submit directly:

1. pulsemcp.com/submit: enter https://github.com/livedotme/mcp (and the remote URL `https://livedot.me/mcp` if asked).
2. Description from [common.md](common.md); contact hello@windline.tech.
